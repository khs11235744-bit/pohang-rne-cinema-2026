- 차민혁팀: /cha/ — 신조어·문화·언어 변화, 12개 장면, 발표자 모드, Q&A 30문항

## 주요 UX
- 발표 시작 전에 1인·2인 발표를 선택하는 팀별 시작 화면. 실제 발표자 이름이 정해지지 않은 구성은 1·2번 발표자로 표기합니다.
- 객석 프로젝터 화면에서 하단 컨트롤러·7분 시간 표시 제거.
- 사운드 켜고 시작/무음으로 시작 선택. 브라우저에서 직접 합성하는 효과음이므로 상용 영화 음악을 사용하지 않습니다.
- 도입/결론 카메라 모션, 페이지별 장면 전환 스위프, CSS 3D 효과, 단계별 등장 효과.
- 접근성 설정(`prefers-reduced-motion`)에 따라 카메라 애니메이션을 줄입니다.
- 발표 중 화살표로 다음/이전, M 키 음소거, F 전체화면, Q 질문지(팀별 지원) 등.
- 신진욱팀은 P 키로 별도 발표자 모드. 차민혁팀은 S, 허준완팀은 S로 기존 발표자 UI 진입.

## 파일 구조
- `site/index.html`: 통합 허브
- `site/shin/`: 신진욱 발표 웹앱의 빌드 결과
- `site/cha/`: 차민혁 발표의 기존 시네마틱 엔진 + 고급 사운드·STAT 30문항
- `site/hu/`: 허준완팀 다크웹 국제공조 기록 + D3 사건 네트워크, 필름 누아르 테마
- `site/seung/`: 신승연팀 PixiJS + Anime.js 신규 웹 발표 · 밝은 학교생활 필드노트 테마
- `seung-source/`: 신승연팀 편집 가능한 소스(Vite · PixiJS · Anime.js)
- `shared/`: 시네마틱 입장·사운드·카메라·발표자 선택 관련 재사용 컴포넌트
- `test-multi.mjs`, `live-multi.mjs`: Windows Chrome/Playwright 통합 검사
- `wrangler.jsonc`: 독립 Cloudflare Worker의 정적 에셋 설정

## 자료의 범위
- 신진욱팀: 동의 응답 106건, 중복 가능 3쌍. 갈등 감소 효과가 아니라 학생들이 사전 합의에 동의한 **인식 비율**임.
- 차민혁팀: 동의 102건(중복 검토 전 잠정), 동일 인적사항 초과 제출 7건. 실제 언어 변화가 아닌 학생의 인식 조사.
- 허준완팀: 1학년 108건 편의표집, 다른 학년·전국 일반화 금지. 범죄수법 안내가 아니라 적법 수사·국제공조 연구.

원본 설문 엑셀이나 학생별 답변·학번·전화번호는 이 허브에 포함하지 않았습니다.

## 배포
연결된 Cloudflare 계정의 프로젝트 `pohang-rne-cinema-2026`로 `wrangler deploy --config wrangler.jsonc` 명령을 실행합니다. 다른 R&E 스튜디오 Worker나 기존 Vercel 프로젝트는 수정하지 않습니다.

라이선스: 각 발표에 사용된 오픈소스 도구는 해당 프로젝트 고지를 유지합니다. 이 저장소의 `cha/licenses` 폴더에는 관련 서드파티 라이선스 텍스트가 포함되어 있습니다.
